🏋️ Sistema de Academia em Java

📌 Descrição:
Aplicação de console desenvolvida em Java para cadastrar alunos em planos de academia Básico e VIP, com cálculo de mensalidades, descontos por fidelidade e opção de personal trainer.

⚙️ Funcionalidades:
Cadastro de alunos em planos Básico e VIP.
Cálculo de mensalidades.
Descontos conforme o período contratado.
Opção de personal trainer no plano VIP.
Validação de dados de entrada.

🧠 Conceitos de POO
Encapsulamento: atributos privados e getters.
Herança: subclasses PlanoBasico e PlanoVip.
Polimorfismo: método calcularMensalidade().
Abstração: classe abstrata Plano.
Interface: Fidelizavel.
🛠️ Tecnologias
Java JDK 25
Git e GitHub

▶️ Como executar
Instale o JDK 25.
Clone o repositório.
Abra o projeto em uma IDE compatível com Java.
Execute a classe principal.
